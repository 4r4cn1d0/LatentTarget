## 3. Target simulator: exact logic

The target reads **only the message text**. It never sees the scenario, the round index or the condition.

```text
candidate_prob[p] = DeBERTa-v3 zero-shot NLI probability for prototype p
                     using: 'The message appeals to {}.'
group[d]          = sum(candidate_prob[p] for p in prototypes[d])
score[d]          = group[d] / sum(group.values())
                     # fairness/risk/expertise rewarded; other unspent

logit             = base_bias
                  + w_match * score[hidden_type]
                  + w_off * sum(score[d] for d != hidden_type)
                  + Normal(0, logit_noise_sd)
P(A)              = sigmoid(logit)
choice            = A with probability P(A), else B
```
